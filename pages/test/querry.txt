3. Paste query di bawah satu persatu
4. Klik butang "Execute Query" (▶)

=========================================================================
NOTES & TIPS
=========================================================================

1. GUNAKAN VARIABLES:
   Query yang ada ($variable) boleh guna dengan Variables JSON:
   {
     "categoryId": 5,
     "first": 10
   }

2. PAGINATION:
   - Gunakan "after" untuk page seterusnya
   - "endCursor" dari response untuk "after" next request
   - "hasNextPage" = true kalau ada page lagi

3. PERFORMANCE:
   - Ambil field yang diperlukan SAHAJA
   - Jangan ambil semua field jika tak perlu
   - Guna "first" untuk limit result

4. CUSTOM FIELDS (jika ada):
   - postViewsCount
   - ppmaAuthor
   - classList
   Kena register di WPGraphQL settings dulu

5. SETTINGS YANG DISYORKAN:
   - Enable Public Introspection: YES (untuk development)
   - Enable GraphQL Debug: YES (untuk development)
   - Max Query Depth: 15
   - Max Query Complexity: 1000
   - Batch Queries: ENABLED
